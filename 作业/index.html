作业一 · 提示词工程师 不写代码，写提示词：让 AI 生成 #mySw4 配置（2 轮迭代）

把 4 个硬性需求“翻译”给 AI：① 无缝循环　② 3.2 秒自动翻页且手动操作后不停止　③ 圆点分页器可点击　④ 初始效果为 cube，让它生成 new Swiper('#mySw4', {...}) 配置。

第 1 轮提示词（故意只说大概）

我的提示词 · 第 1 轮帮我用 Swiper 写个轮播：new Swiper('#mySw4', {...})，要循环播放、3.2 秒左右自动翻页、带圆点分页器，效果用 cube。
new Swiper('#mySw4', {
  loop: true,
  autoplay: true,                            // 错1：等于 delay 3000，不是 3200
  pagination: { el: '.swiper-pagination' },  // 错2：圆点不可点击；错3：没指向本页 #wyPag4
  effect: 'cube'
})

第 1 轮检查结论：AI 漏了 3 处——② 没写 disableOnInteraction: false，手动拖动后自动播放会停；③ 圆点没配 clickable: true，点不动；delay 也没给精确值。第一版提示词败在“只说大概”，没把需求落到参数级。

第 2 轮提示词（把需求说成参数级）

我的提示词 · 第 2 轮重来，4 条硬性要求逐条满足并逐条注释：① loop: true 无缝循环；② autoplay.delay 精确 3200，且 disableOnInteraction: false（手动操作后继续播）；③ pagination 的 el 用 #wyPag4、clickable: true；④ effect: 'cube'。
new Swiper('#mySw4', {
  loop: true,                    // ① 无缝循环
  autoplay: {
    delay: 3200,                 // ② 精确 3.2 秒
    disableOnInteraction: false  // ② 手动操作后不停止
  },
  pagination: {
    el: '#wyPag4',               // ③ 指向本页圆点容器
    clickable: true              // ③ 圆点可点击
  },
  effect: 'cube'                 // ④ 初始效果
})

亲自粘进页面逐条验证

验证方法：把配置里的 #mySw4 换成本页的 #wySw4 粘进底部 script 区（验证后还原），逐条核对：

① 无缝循环：拖到最后一张继续拖，直接接回第一张、不回跳 —— 通过

② 3.2 秒自动翻页、手动不停止：约 3.2 秒翻一张；按住拖动松手后仍继续自动播 —— 通过

③ 圆点可点击：点第 3 个圆点直接跳到第 3 张 —— 通过

④ 初始效果 cube：粘入配置刷新后首屏即立方体翻转 —— 通过（本页演示四按钮版初始仍是 slide，验证时临时粘入）

作业二 · creative 电影感 课堂没讲的第 7 种 effect：AI + 官方示例 257 自学

课堂只讲了 6 种 effect。打开官方示例 swiper/demo/257-effect-creative.html，配合 AI 读懂 creativeEffect 的 transform 写法，为演示四新增第 7 个按钮 [creative 电影感]（上方演示四可点：上一张缩小左移带角度、下一张放大右移带角度，像电影选片墙）。

我的提示词Swiper 的 creative effect 课堂没讲。官方示例 257 里 creativeEffect.prev 写的是 { shadow: true, translate: ['-125%', 0, -800], rotate: [0, 0, -90] }——逐个字段讲清楚 transform 的写法和取值含义，并说明 prev/next 分别管哪些卡片，别只翻译文档。
AI 回答 · 要点prev / next 分别描述「当前卡片左侧（已看过）」和「右侧（还没看）」卡片的待命姿态：translate 是 [x, y, z]，x/y 用百分号、z 用像素；rotate 是 [x, y, z] 三轴角度；shadow 加投影。Swiper 按每张 slide 的 progress 在「原位 → 这个姿态」之间连续插值，所以翻页时卡片是滑过去的，不是瞬移。
// 演示四第 7 个按钮 [creative 电影感] 的关键参数（本页已实现）
if (effectName === 'creative') {
  option.slidesPerView = 1.8;     // 露出两侧卡片，才有“选片墙”
  option.centeredSlides = true;   // 当前卡片居中
  option.creativeEffect = {
    limitProgress: 2,
    prev: {                       // 上一张：缩小 + 左移 + 带角度
      shadow: true,
      translate: ['-55%', 0, -380],
      rotate: [0, 0, -9]
    },
    next: {                       // 下一张：放大 + 右移 + 带角度
      shadow: true,
      translate: ['55%', 0, 120],
      rotate: [0, 0, 9]
    }
  };
}

追问后用自己的话写下来：prev 的 transform 控制“来路”——已经看过的卡片以什么大小、位置、角度退到左边待命；next 的 transform 控制“去路”——还没看的卡片在右边以什么姿态等着进场。translate 的 z 取负是退远（显小）、取正是凑近（显大）。

答辩抽问准备：transform 里的百分号相对 slide 自身的宽/高（x 相对 slide 宽、y 相对 slide 高），不是容器宽；把 rotate 第三位从 ±9 改成 ±20，卡片倾角立刻变 20 度（现场可演示）。

我的提示词 · 加功能再给 #wySw4 加键盘控制：左右方向键翻页。页面里还有其他轮播和输入框，别让键盘抢按键。这个参数课堂没讲，直接给写法和参数说明。
// AI 第 1 版：keyboard: true      问题：全局监听，打字/滚动页面会误触翻页，多个轮播一起动
// 我改成（第 2 版，已用在本页演示四）：
keyboard: {
  enabled: true,          // 开启键盘监听
  onlyInViewport: true    // 轮播出现在视口内才响应方向键
}

答辩四连问自答：

① 这段代码什么意思 —— enabled 打开键盘监听；onlyInViewport 限定「滚到可视区才听键盘」，页面里多个轮播互不抢键。

② AI 第一次给的哪里不对、我改了什么 —— 它只给 keyboard: true，会全局抢按键、打字误触翻页；我改成对象写法并补 onlyInViewport: true。

③ 新参数的作用 —— onlyInViewport: true：哪个轮播在视口里，方向键就归哪个。

④ 现场把 delay 改成指定值 —— 把 initSw4 里 autoplay.delay 从 3200 改成指定值（如 1500），每张停留 1.5 秒就翻页；因为 disableOnInteraction: false，手动滑动后仍按新节奏继续自动播。
